🧪 Exploratory Testing Report – KaBuM!

Este repositório apresenta os resultados de sessões de teste exploratório realizadas no site KaBuM!, com foco em identificar problemas de usabilidade, inconsistências e oportunidades de melhoria.

📌 Objetivo

Avaliar a experiência do usuário e o comportamento do sistema através de testes não roteirizados, utilizando heurísticas para guiar a exploração.

🧭 Abordagem

Foram utilizadas técnicas de teste exploratório com charters estruturados, aplicando as seguintes heurísticas:

🔄 CRUD – criação, leitura, atualização e remoção

📏 Vazio / Cheio / Limite – testes em extremos

🔁 Fluxo interrompido – navegação, refresh e troca de contexto
